# komei-portfolio
転職活動用のポートフォリオサイトです。

## 目的
インフラ運用・保守から開発エンジニアを目指すにあたり、自分の経歴と志望理由を一枚で伝えるために制作しました。

## 使用技術
- HTML / CSS（フレームワーク不使用）
- Netlify（ホスティング）

## 工夫した点
- flexboxによるレイアウト、2段階のブレークポイント（799px / 500px）
- 画像の最適化（合計17MB → 1MB以下）

## 学んだこと・つまずいた点
- 画像の表示サイズが重かったため圧縮して軽量化
- デバイスによってレイアウトが異なるため最適化が必要
