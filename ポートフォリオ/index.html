WORKS

My Portfolio（本サイト）

HTML / CSS

目的：転職活動用に、自分の経歴と「なぜ開発に進むのか」を伝えるサイトとして制作。
構成：HOME → ABOUT → SKILL → WORKS → CONTACT の1ページ構成。
